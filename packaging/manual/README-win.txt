Delay Basics Lab (Beta) — Windows 手動インストール / Manual install
by Johan Plus Kei

！注意：Windows 版はビルドが通ることのみ確認済みで、実機での動作確認はしていません。
  不具合があれば GitHub の Issues でお知らせください。
! Note: The Windows build compiles, but has NOT been tested on a real Windows machine yet.
  Please report problems via GitHub Issues.

【日本語】
対応：Windows 10 / 11（64bit）

1. zip を展開する前に、zip を右クリック › プロパティ › 「許可する」にチェック › OK。
2. 展開した「Delay Basics Lab.vst3」フォルダを丸ごと次へコピー（管理者の確認が出たら「続行」）：
   C:\Program Files\Common Files\VST3
3. 単体で使う場合は「Delay Basics Lab.exe」を好きな場所に置いて起動。
4. DAW でプラグインを再スキャン。
   Live は「設定 › プラグイン」で「VST3 プラグイン システムフォルダ」をオン › 再スキャン。

アンインストール：上記フォルダから「Delay Basics Lab.vst3」を削除。
手動が面倒な場合は Releases ページの .exe インストーラー版も使えます
（「Windows によって PC が保護されました」→「詳細情報」→「実行」）。

【English】
Requires Windows 10 / 11 (64-bit)

1. Before extracting, right-click the zip › Properties › tick "Unblock" › OK.
2. Copy the whole "Delay Basics Lab.vst3" folder to:
   C:\Program Files\Common Files\VST3
3. For standalone use, put "Delay Basics Lab.exe" anywhere and run it.
4. Rescan plug-ins in your DAW.

Uninstall: delete "Delay Basics Lab.vst3" from the folder above.
An .exe installer is also available on the Releases page
("Windows protected your PC" -> More info -> Run anyway).
